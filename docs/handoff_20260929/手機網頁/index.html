Isaac Sim 3F 走廊，實車同一套 ROS（NDT 定位 + routing + RL policy），速度 0.7、ORCA 行人。 72 趟全部來回抵達、真的碰到 0 次，這裡挑 6 段最有看頭的（原檔在 PC 上，已壓縮成手機用）。 9/24 晚間更新：已修正 Character_04（白色警察）鬼影、斜前方鏡頭穿牆、行人快停下時突然轉身 180°、車後鏡頭在轉角貼牆（改成往走廊中間橫移）。影片都是最新版本。

三視角合成

斜前方鏡頭怎麼避牆

  1. 每一幀從車往「預定的鏡頭位置」（車前 3.2 m、左 1.4 m、高 1.7 m）拉一條線。
  2. 線碰到牆，就把鏡頭停在牆前 0.3 m；沒碰到就維持原位。
  3. 「牆」用兩種資料判斷，取較近的：物理碰撞體，以及畫面上看得到的建築網格（有些門和內凹處只有外觀、沒有碰撞體，只看碰撞體會漏掉）。
  4. 拉近立刻生效（任何一幀都不進牆），放回原位慢慢來（約 1 秒），畫面不會抽動。
效果：同一趟的全黑／全白幀 172 → 6。剩下的是行人剛好穿過鏡頭，不是牆（避牆刻意不看行人，否則鏡頭會一直抖）。車後鏡頭也用同一套，另外會量左右離牆距離、往走廊中間橫移（最多 0.8 m），轉角時不會被牆角擋住一半。
